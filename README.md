# Laboratório de JavaScript  25 Desafios Interativos
Laboratório interativo de JavaScript com 25 desafios práticos, explorando lógica de programação, manipulação do DOM, eventos, filtros, favoritos e armazenamento de dados com LocalStorage. Desenvolvido com HTML, CSS e JavaScript, utilizando uma identidade visual em branco e azul-noturno com o tema NEVER LAND.
